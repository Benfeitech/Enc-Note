FAQ

Questions, answered.

What is Enc-Note?

Enc-Note is a private sharing tool for temporary text and image messages controlled by expiration, passwords and maximum successful openings.

Does the message really disappear?

The note becomes inaccessible when its expiration is reached or its allowed successful openings are consumed.

Can I send an image without text?

Yes. A note can contain only an image, only text, or both.

How does the number of openings work?

It counts successful openings, not unique people. For example, a note configured for five openings can be successfully opened five times in total.

Can the sender know when the note was opened?

Yes. Enc-Note creates a private status link for the sender showing opening progress and timing information without exposing the secret content.

Does the recipient need an account?

No. The recipient uses the secure note link directly.
